## Продукты

| Репозиторий | Что это | Ссылки |
|---|---|---|
| **[buff-community](https://github.com/buffsystems/buff-community)** | **Buff Community Edition** — ИИ-разработчик, аналитик и база знаний для вашей компании на вашей машине, с вашей моделью. Бесплатно для внутреннего использования одной организацией. | [Релизы](https://github.com/buffsystems/buff-community/releases) · [Документация](https://buff.systems/docs/self-hosted/community) |
| **[buff-code](https://github.com/buffsystems/buff-code)** | **Buff Code** — среда разработки для инженеров, которые пишут код сами: консоль и приложение на моделях, знаниях и подключениях вашей организации или на вашей собственной модели. | [Релизы](https://github.com/buffsystems/buff-code/releases) · [Документация](https://buff.systems/docs/buff-code) |
| **[buff-mobile](https://github.com/buffsystems/buff-mobile)** | **Buff Code и Buff на телефоне** — приложение для iPhone и Android: ведите сессии агента на своём компьютере и принимайте решения по задачам команды. | [Релизы](https://github.com/buffsystems/buff-mobile/releases) · [Документация](https://buff.systems/docs/mobile) |
| **[buff-guardrails](https://github.com/buffsystems/buff-guardrails)** | **Buff Guardrails** — шлюз к ИИ-моделям, который убирает персональные данные и секреты из запросов и возвращает их в ответ: LiteLLM + Presidio + распознаватели российских документов, целиком в вашем периметре. | [Описание](https://buff.systems/guardrails) |
| **[buff-connector](https://github.com/buffsystems/buff-connector)** | **Коннектор Buff** — агент в вашем периметре: ИИ-агенты Buff работают с кодом, трекерами и документами, а контент, ключи и интеллектуальная собственность остаются у вас. | [Релизы](https://github.com/buffsystems/buff-connector/releases) · [Документация](https://buff.systems/docs/connector) |

Ещё: **[buff-ui](https://github.com/buffsystems/buff-ui)** — дизайн-система Buff: токены, CSS-компоненты и обёртки React.

Вопросы и предложения по продукту — в issues соответствующего репозитория. Остальное — [info@buff.systems](mailto:info@buff.systems).
